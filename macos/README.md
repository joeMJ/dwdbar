# dwdbar für macOS

Vorbereitetes Modul für eine native macOS MenuBar-App (Swift / SwiftUI `MenuBarExtra`).

## Geplante Features
- Menüleisten-Icon (Top Bar) mit Wettericon, Temperatur, relativer Feuchte und berechnetem Taupunkt
- Dropdown-Popup beim Klick mit aktuellem Wetter, 10h-Stundenvorhersage ("Heute") und 5-Tage-Vorhersage
- Direkte DWD Bright Sky API Abfrage & optionale Home Assistant REST-Anbindung
- Integrierte Einstellungsansicht für Station, HA-Token und Anzeigeoptionen
